📐 核心算法流程图

📋 算法定位

当现场有五花八门的设备（摄像头、传感器、PLC、仪表）要把数据送到五花八门的AI应用（人脸识别、预测维护、质检、能耗优化）里去时，以前需要程序员针对每一对"设备+应用"手写代码。本算法就是把"手写代码"的过程自动化、配置化。

🔄 核心算法流程总图

📥 算法输入

  • 设备标识：Device ID / MAC地址 / 序列号
  • 物理接口：RS485 / RS232 / TCP / MQTT / Modbus / OPC-UA
  • 原始数据样本：前N条报文 / 前N秒信号（字节流/模拟量）
  • 目标AI需求：用户选择的AI应用类型 / 场景配置

⚙️ 算法处理

  1. 数据结构特征分析（帧头帧尾/校验/分隔符）
  2. 时序特征分析（采样频率/周期/突变）
  3. 内容特征分析（数值范围/枚举值/编码）
  4. 驱动库匹配（协议转换表查表）
  5. 格式转码（方言→普通话）
  6. 模型张量封装（输入标准化）

📤 算法输出

  • 标准JSON数据：统一格式的设备数据
  • 标准张量：AI模型可直接推理的Tensor
  • 集成配置文件：设备-算法绑定关系
  • 边缘下发指令：盒子执行计划（MQTT）
  • 运行状态流：心跳+指标监控
